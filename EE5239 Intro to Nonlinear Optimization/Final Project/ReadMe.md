This project explores the implementation and testing of the IPOPT algorithm on selected Hock-Schittkowski problems from the CUTEST dataset. The IPOPT (Interior Point Optimizer) algorithm is used for solving constrained optimization problems.

The code for this project must be run on a Mac or Linux system or Windows Subsystem for Linux (WSL). CUTEst must be installed on your machine and there are several environment variables that must be set. See the PyCutest documentation for more details: https://jfowkes.github.io/pycutest/_build/html/index.html
