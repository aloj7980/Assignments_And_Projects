This project explores the prediction of credit defaults. The dataset is highly imbalanced with non-default being much more common than default. We address this using synthetic oversampling techniques and evaluation metrics tailored to the situation such as F2 score. After preprocessing the data, engineering its features and generating synthetic samples of the minority class, several models were fit and a Naive Bayes classifier performed the best. Different values of the smoothing parameter were experimented for this Gaussian Naive Bayes model as well as for a Hybrid Naive Bayes model. In almost all cases, the models performed better when trained on the data that contained synthetic samples of the minority class than on the original training data.
