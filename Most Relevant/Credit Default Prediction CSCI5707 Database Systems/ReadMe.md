This project that I completed with one other student for my CSCI5707 graduate course that I took in the fall 2024 semester explores the prediction of credit defaults. The dataset is highly imbalanced with non-default being much more common than default. This is addressed using synthetic oversampling techniques and evaluation metrics tailored to the situation. After preprocessing the data, engineering its features and generating synthetic samples of the minority class, several models were fit and a Naive Bayes classifier performed the best. Different values of the smoothing parameter were experimented for this Gaussian Naive Bayes model as well as for a Hybrid Naive Bayes model. In almost all cases, the models performed better when trained on the data that contained synthetic samples of the minority class than on the original training data.

A random forest, an adaboost model, and an XGBoost model were initallly fit with grid search hyperparameter tuning. Only a few hundred combiantions were fit for each model due to the size of the dataset, and this resulted in the death of the Jupyter notebook kernel. That is why there are two Jupyter notebooks. RF_Adaboost_XGBoost_Hyperparameter_Tuning.ipynb contains everything that was done before the kernel died, and Everything_Else.ipynb contains everything from RF_Adaboost_XGBoost_Hyperparameter_Tuning.ipynb other than the hyperparameter tuning step that killed the kernel along with the training of several additional models and the further analysis of various Naive Bayes models described in the previous paragraph.
